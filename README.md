## 서비스 구성

메뉴는 **4개**입니다 — **마이러닝 · 코스 지도 · 연습일지 · 이용안내**.
매일 여는 건 사실상 하나(마이러닝)입니다.

| 화면 | 내용 |
|---|---|
| **마이러닝** ⭐ | 오늘 할 스텝 한 장 · 연속 기록 · 오늘의 복습(최대 2장) · 진행 링 · 최근 연습 · 자료실 · 동기화 |
| **코스 지도** | 21스텝 7막 조망 + 전환의 사다리 8계단. 고르는 곳이 아니라 **어디까지 왔는지 보는 곳** |
| **연습일지** | 날짜별 기록. 「선생님 검수용 복사」로 채팅에 붙여넣어 피드백 |
| **이용안내** | 하루 사용법 · 화면 기호 · 자주 막히는 질문 |

한 스텝 안에 그날 필요한 것이 전부 들어 있습니다:

```
왜 지금 이걸 → 오늘의 복습 2장 → 분 단위 드릴 → 손 모양(그 곡의 실제 조)
→ 👂 이 소리가 나면 틀린 것 → 곡의 어느 구간을 → 강의 1편 → 오늘 들을 것
→ 막히면 → 통과 기준 2단 → 더 깊게(접힘: 이론·사다리·곡 전문)
```

### 핵심 장치

- **조성 인식 보이싱 엔진** (`voicing.js`) — 코드 심볼에서 셸/가이드톤/루트리스를
  계산해 **그 곡의 실제 조**로 건반을 그린다. 이명동음 보존(Cdim7 = C·E♭·G♭·B♭♭)
- **콜드 스타트 2단 게이트** — 통과 기준 3개를 채우면 *예비 통과*(◐ 점선),
  **다음 날** 워밍업 없이 첫 시도로 재통과해야 *확정*(✓ 실선).
  어제의 성공은 위조할 수 없다
- **복습 덱** (Leitner 1/4/11일) — 확정한 스텝이 잊을 때쯤 다시 도래한다.
  하루 최대 2장, 기존 워밍업 자리를 대신하므로 **분량이 늘지 않는다**
- **연속 기록 + 최소 실행** — 5분만 해도 연속이 유지된다
- **오류 탐지 카드** — "이 소리가 나면 틀린 것". 혼자 연습하는 사람의 즉시 피드백

## 핵심 설계 — 전환의 사다리

이미 치는 것에서 **딱 한 계단씩** 바꿉니다. 같은 `Dm7 – G7 – Cmaj7` 하나로 8단계:

```
0 블록 → 1 손 분리 → 2 셸 → 3 가이드톤(★) → 4 루트리스 A/B
→ 5 오른손 멜로디 → 6 컴핑 리듬 → 7 즉흥
```

**rung 3(가이드톤)** 이 아하 모먼트입니다 — 손이 점프를 멈추고 반음으로만 이어집니다.

## 진도 동기화

진도·연습일지는 기본적으로 **그 브라우저에만** 저장됩니다(localStorage). 기기 간에 이어지지 않습니다.

여러 기기에서 이어서 쓰려면 두 가지 방법이 있습니다.

- **자동 동기화** — Supabase를 붙이면 로그인한 기기끼리 자동으로 합쳐집니다.
  설정 방법: [SUPABASE_SETUP.md](./SUPABASE_SETUP.md) (약 5분, 무료)
- **파일로 옮기기** — 설정 없이 바로 가능. `나의 진도 → 기기 간 동기화`에서
  **내보내기**로 JSON을 받아 다른 기기에서 **가져오기**.

병합은 **합집합**입니다 — 어느 기기에서든 체크한 통과 기준은 살아남습니다.

## 기술

```
index.html          앱 진입
assets/theme.css    디자인 시스템 (Blue Note 다크 + 브라스)
assets/music.js     SVG 건반 렌더러 — 외부 라이브러리 0
assets/content.js   콘텐츠 단일 진실원
assets/course.js    실행 레이어 — 21스텝 (id 참조만)
assets/app.js       해시 라우터 + 뷰 렌더러 + 진도 추적
```

진도·연습일지는 브라우저 `localStorage`에 저장됩니다(기기 간 동기화 없음).
