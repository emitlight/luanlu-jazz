## 서비스 구성

메뉴는 5개입니다 — **홈 · 연습 코스 · 나의 진도 · 연습일지 · 이용안내**.

매일 할 일은 하나입니다: 홈의 「이어서 하기」를 눌러 오늘 스텝 한 장을 열고,
적힌 분 단위 드릴대로 연습한 뒤, **통과 기준 3개**를 체크한다.

한 스텝 안에 그날 필요한 것이 전부 들어 있습니다:

```
왜 지금 이걸 → 분 단위 드릴 → 손 모양(SVG 건반) → 곡의 어느 구간을
→ 강의 1편 → 오늘 들을 것 1곡 → 막히면 → 통과 기준 → 더 깊게(접힘)
```

전환의 사다리 · 테크닉 이론 · 리얼북 곡 분해는 별도 메뉴가 아니라
각 스텝 하단 **「더 깊게」** 안에 접혀 있습니다.

## 핵심 설계 — 전환의 사다리

이미 치는 것에서 **딱 한 계단씩** 바꿉니다. 같은 `Dm7 – G7 – Cmaj7` 하나로 8단계:

```
0 블록 → 1 손 분리 → 2 셸 → 3 가이드톤(★) → 4 루트리스 A/B
→ 5 오른손 멜로디 → 6 컴핑 리듬 → 7 즉흥
```

**rung 3(가이드톤)** 이 아하 모먼트입니다 — 손이 점프를 멈추고 반음으로만 이어집니다.

## 진도 동기화

진도·연습일지는 기본적으로 **그 브라우저에만** 저장됩니다(localStorage). 기기 간에 이어지지 않습니다.

여러 기기에서 이어서 쓰려면 두 가지 방법이 있습니다.

- **자동 동기화** — Supabase를 붙이면 로그인한 기기끼리 자동으로 합쳐집니다.
  설정 방법: [SUPABASE_SETUP.md](./SUPABASE_SETUP.md) (약 5분, 무료)
- **파일로 옮기기** — 설정 없이 바로 가능. `나의 진도 → 기기 간 동기화`에서
  **내보내기**로 JSON을 받아 다른 기기에서 **가져오기**.

병합은 **합집합**입니다 — 어느 기기에서든 체크한 통과 기준은 살아남습니다.

## 기술

```
index.html          앱 진입
assets/theme.css    디자인 시스템 (Blue Note 다크 + 브라스)
assets/music.js     SVG 건반 렌더러 — 외부 라이브러리 0
assets/content.js   콘텐츠 단일 진실원
assets/course.js    실행 레이어 — 21스텝 (id 참조만)
assets/app.js       해시 라우터 + 뷰 렌더러 + 진도 추적
```

진도·연습일지는 브라우저 `localStorage`에 저장됩니다(기기 간 동기화 없음).
